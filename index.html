Prototype Information

About the Monitoring Tool

This HTML-only preview demonstrates the intended DOLE-RO7 workflows.

Included features

Live Leaflet/OpenStreetMap maps, colored program markers, dashboard filters, activity registration, on-demand Nominatim location search, province and field office validation, browser-based saving, editing and deletion, CSV export, and JSON backup/restore.

This version saves data using localStorage on this browser/device. Records are not shared with other users, and there is no login, MySQL connection, or server-side security. Use test/demo records only.

Field Office Coverage

CPFO — Cebu Provincial Field Office

TCFO — Tri-City (Cebu City, Mandaue City, Lapu-Lapu City)

BFO — Bohol Field Office

Geocoding notes

Place search and map-click reverse lookups require internet access and may depend on OpenStreetMap/Nominatim data accuracy. Searches occur only when requested, not for each keystroke. This demo verifies administrative location text returned by the geocoder; a production deployment should add official polygon-boundary GIS validation and a server-side geocoding proxy/cache.

Local Data Controls

Manage this browser's prototype records. Create a JSON backup first if you wish to keep your entries.

Next Phase: PHP / MySQL
